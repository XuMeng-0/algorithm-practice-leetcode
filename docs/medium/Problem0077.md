# 77. 组合

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/combinations  
> &zwnj;**难度**&zwnj;: 中等

## 题目描述

定两个整数 n 和 k，返回范围 [1, n] 中所有可能的 k 个数的组合。

你可以按 任何顺序 返回答案。

## 解题思路

观察不同的 n 和 k 的组合，可以找出规律

f(n,k) = f(n-1,k) + m(f(n-1,k-1))

m(x) 的作用是 对集合 x 中的每一个子元素添加一个 n

例如：

n = 4, k = 3 的组合为 1,2,3 1,2,4 1,3,4 2,3,4
n = 3, k = 3 的组合为 1,2,3
n = 3, k = 2 的组合为 1,2 1,3 2,3

对 n = 3, k = 2 的组合的每一个元素添加一个 n (n = 4) 的到 1,2,4 1,3,4 2,3,4
n = 3, k = 3 的组合为 1,2,3
将上述两组元素合并得到 1,2,3 1,2,4 1,3,4 2,3,4 ,这就是 n = 4,k = 3 的所有组合。

1. 步骤一：处理 n = k 的情况，将 1 到 n 的所有值作为一个组合返回，共 1 个组合，有 n 个元素
2. 步骤二：处理 k = 1 的情况，将 1 到 n 的每一个值作为一个组合返回，共 n 个组合，每个组合有 1 个元素
3. 步骤三：采用递归思想处理其他情况。
