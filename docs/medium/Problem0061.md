# 61. 旋转链表

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/rotate-list  
> &zwnj;**难度**&zwnj;: 中等

## 题目描述

给你一个链表的头节点 head ，旋转链表，将链表每个节点向右移动 k 个位置。

示例1

head = [1,2,3,4,5]

k = 1 =>  [5,1,2,3,4]

k = 2 =>  [4,5,1,2,3]

示例2

head = [0,1,2]

k = 1 => [2,0,1]

k = 2 => [1,2,0]

k = 3 => [0,1,2]

k = 4 => [2,0,1]

## 解题思路

观察示例可以发现：

当 k = 1 时，需要将最后一个节点移动到链表的头部

当 k = 2 时，需要将最后一个节点移动到链表的头部，然后在新链表上将最后一个节点移动到头部

所以，k 的值就是需要在链表上重复执行最后一个节点移动到头部操作的次数

1. 步骤一：处理特殊情况，当链表的节点个数为 0 时，返回空链表
2. 步骤二：遍历链表，计算链表的长度
3. 步骤三：根据 k 和 链表长度，计算实际需要执行最后一个节点前置操作的次数
4. 步骤四：执行最后一个节点前置操作若干次

最后一个节点前置操作步骤：

1. 步骤一：处理节点个数小于 2 的特殊情况，直接返回原始链表
2. 步骤二：遍历链表，找到最后一个节点和倒数第二个节点
3. 步骤三：将倒数第二个节点作为最后一个节点
4. 步骤四：将原来的最后一个节点作为新的头结点
