# 73. 矩阵置零

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/set-matrix-zeroes  
> &zwnj;**难度**&zwnj;: 中等

## 题目描述

给定一个 m x n 的矩阵，如果一个元素为 0 ，则将其所在行和列的所有元素都设为 0 。请使用 原地 算法。

## 解题思路

1. 步骤一：定义用于存放矩阵坐标的 set 集合，横坐标一个集合，纵坐标一个集合
2. 步骤二：遍历矩阵，将所有值为 0 的元素的横坐标和纵坐标，分别存放在对应的 set 集合中
3. 步骤三：遍历矩阵，如果一个元素的横坐标或纵坐标和 set 集合中的某个元素相等，则将矩阵元素置零
