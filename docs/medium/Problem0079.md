# 79. 单词搜索

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/word-search  
> &zwnj;**难度**&zwnj;: 中等

## 题目描述

给定一个 m x n 二维字符网格 board 和一个字符串单词 word 。如果 word 存在于网格中，返回 true ；否则，返回 false 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

## 解题思路

1. 步骤一: 遍历字符网格，找到网格中所有的与 word 首字母相同的字符，记录其位置。对每一个位置分别执后续步骤
2. 步骤二：将第一步找到的字符替换为 . 避免后续重复使用
3. 步骤三：将 word 的第二个字母和第一个位置的相邻位置的字符比较，记录所有相同的位置
4. 步骤四：如果记录的字符相同的位置个数为 0 ，则返回 false。否则对每一个位置分别执行后续步骤
5. 步骤五：将第三步找到的字符替换为 . 避免后续重复使用
6. 步骤六：将 word 的第三个字母和第二个位置的相邻位置的字符比较，记录所有相同的位置
7. 步骤七：如果记录的字符相同的位置个数为 0 ，则返回 false。否则对每一个位置分别执行后续步骤
8. 步骤八：按照步骤二、三、四和五、六、七的规律执行，直到用完 word 所有的的字母为止
