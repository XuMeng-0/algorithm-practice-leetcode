# 78. 子集

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/subsets  
> &zwnj;**难度**&zwnj;: 中等

## 题目描述

你一个整数数组 nums ，数组中的元素 互不相同 。返回该数组所有可能的子集（幂集）。

解集 不能 包含重复的子集。你可以按 任意顺序 返回解集。

## 解题思路

一个集合的所有子集 = 空集 + 包含一个元素的子集 + 包含两个元素的子集 + ... + 包含所有元素的子集

包含 n 个元素的子集 = 从所有元素中取 n 个元素的组合

1. 步骤一：定义一个方法，用于求从 n 个元素中取 k 个元素的组合，也就是求包含 k 个元素的子集
2. 步骤二：定义一个集合，用来盛放所有的子集
3. 步骤三：将空集合加入集合
4. 步骤四：循环分别将包含 1 个、2个 直至 n 个元素的子集加入集合
