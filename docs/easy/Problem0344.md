# 344. 反转字符串

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/reverse-string  
> &zwnj;**难度**&zwnj;: 简单

## 题目描述

编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 s 的形式给出。

不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

## 解题思路

1. 步骤一：将第一个元素和最后一个元素交换位置
2. 步骤二：将第二个元素和倒数第二个元素交换位置
3. 步骤三：依次交换对应位置的元素，直到需要交换的位置相同或交换的元素位置相邻为止。

元素数量为奇数时，最后需要交换的元素位置相同。
元素数量为偶数时，交换的元素位置相邻，则结束。
