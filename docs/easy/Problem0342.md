# 342. 4 的幂

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/power-of-four  
> &zwnj;**难度**&zwnj;: 简单

## 题目描述

给定一个整数，写一个函数来判断它是否是 4 的幂次方。如果是，返回 true ；否则，返回 false 。

整数 n 是 4 的幂次方需满足：存在整数 x 使得 n == 4 的 x 次方

## 解题思路

1. 步骤一：由于在整数范围内，4 的幂的最小值为 1，所以如果 n < 1 ，那么 n 不是 4 的幂
2. 步骤二：计算 4 的幂的所有值，从小到大排列
3. 步骤三：将 n 依次和每一个值比较，如果 n 和某个值相等则是 4 的幂；如果大于前一个小于后一个则不是 4 的幂
