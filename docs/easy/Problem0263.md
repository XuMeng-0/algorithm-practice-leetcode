# 263. 丑数

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/ugly-number  
> &zwnj;**难度**&zwnj;: 简单

## 题目描述

给你一个整数 n ，请你判断 n 是否为 丑数 。

丑数 就是只包含质因数 2、3 和 5 的 正整数。

## 解题思路

求给定数字的所有因数，过滤出质因数，判断质因数中是否存在大于 5 的，存在则不是丑数，否则是。

1. 步骤一：判断给定的数字是否是正整数。如果不是，则不是丑数，否则执行下一步
2. 步骤二：找到数字的每一个质因数，判断其是否大于五。如果大于五，则不是丑数，否则执行下一步
3. 步骤三：如果没有找到大于的质因数，那么该数字是丑数。

质数的判断：
找出数字的所有因数，如果因数的个数大于2，那么不是质数，否则是。
等价于  
判断数字有没有除 1 和 自身之外的其他因数，如果有，那么不是质数；否则是。
