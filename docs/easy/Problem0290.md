# 290. 单词规律

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/word-pattern  
> &zwnj;**难度**&zwnj;: 简单

## 题目描述

给定一种规律 pattern 和一个字符串 s ，判断 s 是否遵循相同的规律。

这里的 遵循 指完全匹配，例如， pattern 里的每个字母和字符串 s 中的每个非空单词之间存在着双向连接的对应规律。具体来说：

- pattern 中的每个字母都 恰好 映射到 s 中的一个唯一单词。

- s 中的每个唯一单词都 恰好 映射到 pattern 中的一个字母。

- 没有两个字母映射到同一个单词，也没有两个单词映射到同一个字母。

## 解题思路

1. 步骤一：将 pattern 和 s 拆分为字符串数组
2. 步骤二：以 pattern 元素为键，s 元素为值，将元素添加 map 集合中
3. 步骤三：在添加时判断 pattern 和 s 的元素能否一一对应

map 集合中键和值是否一一对应的判断

1. 步骤一：以键为参数取集合的值
2. 步骤二：判断集合中取出的目标值是否为空，非空执行步骤三，空执行步骤四
3. 步骤三：判断目标值和准备加入集合的值是否相同，不同代表一个键对应了两个不同的值
4. 步骤四：判断准备加入集合的值是否已经存在于集合中，存在意味着一个值对应了两个不同的键，不存在执行步骤五
5. 步骤五：将准备加入集合的键和值加入集合
