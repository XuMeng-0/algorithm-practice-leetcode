# 268. 丢失的数字

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/missing-number  
> &zwnj;**难度**&zwnj;: 简单

## 题目描述

给定一个包含 [0, n] 中 n 个数的数组 nums ，找出 [0, n] 这个范围内没有出现在数组中的那个数。

## 解题思路

1. 步骤一: 对数组元素进行排序
2. 步骤二：如果第一个元素不是 0 ，那么丢失的数字为 0
3. 步骤三：如果最后一个元素的值和数组的长度不相等，那么丢失的数字的值为 数组的长度
4. 步骤四：依次判断每一个元素和后一个元素是否相差 1 ，如果不是，那么丢失的数字的值为前一个元素 +1
