# 338. 比特位计数

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/counting-bits  
> &zwnj;**难度**&zwnj;: 简单

## 题目描述

给你一个整数 n ，对于 0 <= i <= n 中的每个 i ，计算其二进制表示中 1 的个数 ，返回一个长度为 n + 1 的数组 ans 作为答案。

示例 1：

输入：n = 2
输出：[0,1,1]
解释：
0 --> 0
1 --> 1
2 --> 10

示例 2：

输入：n = 5
输出：[0,1,1,2,1,2]
解释：
0 --> 0
1 --> 1
2 --> 10
3 --> 11
4 --> 100
5 --> 101

## 解题思路

1. 步骤一: 创建整数数组，长度为 n + 1，用来存放从 0 到 n 的每个数的二进制形式中 1 的个数
2. 步骤二：求从 0 到 n 的每个数的二进制形式中 1 的个数，将计算结果保存到数组的对应位置中。

求某个数的二进制形式中 1 的个数：除 2 取余法

1. 步骤一：定义一个整数变量，用来记录 1 的个数，初始值为 0
2. 步骤二：求该数除以 2 的商，对 2 取余的余数，若余数为 1，1个数加 1
3. 步骤三：将商作为被除数，求除以 2 的商，对 2 取余的余数，若余数为 1，1个数加 1
4. 步骤四：重复执行步骤三，直到商为 0 为止
