# 326. 3 的幂

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/power-of-three  
> &zwnj;**难度**&zwnj;: 简单

## 题目描述

给定一个整数，写一个函数来判断它是否是 3 的幂次方。如果是，返回 true ；否则，返回 false 。

整数 n 是 3 的幂次方需满足：存在整数 x 使得 n == 3 的 x 次方 。

## 解题思路

1. 步骤一：在整数范围内，3 的 x 次方的最小值为 1，所以当 n < 1 时，n 不是 3 的幂次方
2. 步骤二：计算 3 的 x 次方，值按照顺序从小到大排列
3. 步骤三：将 n 依次和每一个值比较。如果 n 和某个值相等，那么 n 是 3 的幂次方；如果 n 大于前一个值，小于后一个，那么 n 不是 3
   的幂次方
