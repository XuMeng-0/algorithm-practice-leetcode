# 257. 二叉树的所有路径

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/binary-tree-paths  
> &zwnj;**难度**&zwnj;: 简单

## 题目描述

给你一个二叉树的根节点 root ，按 任意顺序 ，返回所有从根节点到叶子节点的路径。

叶子节点 是指没有子节点的节点。

## 解题思路

递归

1. 步骤一：判断根节点是否为 null，若是返回空集合；否则执行下一步
2. 步骤二：判断根节点是否存在左右子树，若无将根节点添加到集合中返回，否则执行下一步
3. 步骤三：将左右子树的路径前拼接根节点的值，返回

左右子树的路径获取方法，和整棵树的路径方法相同。
