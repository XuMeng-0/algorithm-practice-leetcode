# 367. 有效的完全平方数

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/valid-perfect-square  
> &zwnj;**难度**&zwnj;: 简单

## 题目描述

给你一个正整数 num 。如果 num 是一个完全平方数，则返回 true ，否则返回 false 。

完全平方数 是一个可以写成某个整数的平方的整数。换句话说，它可以写成某个整数和自身的乘积。

不能使用任何内置的库函数，如 sqrt 。

## 解题思路

1. 步骤一：计算从 1 开始的所有的完全平方数，从小到大排列
2. 步骤二：将 num 和依次完全平方数比较，如果有相同的，则 num 是完全平方数。如果 num 大于前一个小于后一个，则不是完全平方数。
