# 345. 反转字符串中的元音字母

> &zwnj;**原题链接**&zwnj;: https://leetcode.cn/problems/reverse-vowels-of-a-string  
> &zwnj;**难度**&zwnj;: 简单

## 题目描述

给你一个字符串 s ，仅反转字符串中的所有元音字母，并返回结果字符串。

元音字母包括 'a'、'e'、'i'、'o'、'u'，且可能以大小写两种形式出现不止一次。

## 解题思路

1. 步骤一：交换第一个元音字母和最后一个元音字母
2. 步骤二：交换第二元音字母和倒数第二个元音字母
3. 步骤三：依次交换对应位置的元音字母，直到需要交换的字母位置相同或交换后的字母位置相邻为止

判断一个字母是否是元音字母：
if-else switch-case 等条件语句判断其是否是元音字母中的一个
switch-case 语句在 Kotlin 中的形式为 when 语句
